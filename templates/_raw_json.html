{# The Raw JSON panel's body, shared by browser.html and as.html: how to get the same answer from curl and over MCP, and the tree static/js/app.js draws from #page-data when the panel first opens. #}

Any non-browser client gets JSON — curl, wget and friends already qualify:

curl {{ api_base }}{{ view.target }}

AI agents can call it over MCP — paste this into Claude, Cursor, or any MCP client:

{{ api_base }}mcp
claude mcp add --transport http whatismyip {{ api_base }}mcp

Tools: {{ mcp_tools | join(', ') }}. whoami_caller reports whoever opened the connection — your own machine from a local client like Claude Code, a datacenter from a hosted one like claude.ai. It flags an address on a datacenter list as likely hosted, but cannot be sure otherwise, so open this page in a browser when you need certainty.
