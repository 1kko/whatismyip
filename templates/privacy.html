PRIVACY

What this site records, and who else sees a lookup

What is logged

  • Every lookup, from this page, the JSON API or the text API, writes one log line: the time, your IP address and what you looked up. Opening the home page is a lookup of your own address. Something with an @ in it, such as an email address, is refused, and that line records only that it had one; the web server's own access line and the request's trace, below, still carry the path as sent.
  • Refused requests. When a request is blocked, rate limited or banned, the log keeps your IP address and why, with the country GeoIP puts that address in or the path you asked for where the rule turns on them.
  • Failures. When a lookup fails, the log names the domain or address that failed, without yours.
  • MCP tool calls are not logged, except a failed one, which is logged as above: its target, without your address.

How long it is kept

  • The log file on the server, service.log, starts afresh every day and keeps the last {{ log_retention }} of old files. Older ones are deleted.
    • {# Operator: once the SigNoz and container-log retention are confirmed, state them here in days instead of pointing at those systems' own settings. #}
  • The same lines also go to the server's console log and, with a trace of each request (method, path and query, so what was looked up, plus status, timing and user-agent), to the operator's SigNoz monitoring. How long those keep them is set in the monitoring and hosting systems themselves, not by this service.
  • A ban keeps your IP address, the reason and, where they apply, the path and the country until it expires: {{ ban_rate_limit }} for going over the rate limit, {{ ban_suspicious }} for a request shaped like a vulnerability probe. A ban set by hand lasts until it is lifted.
  • The rate limiter holds the times of your recent requests in memory for a few minutes. None of it is written down.
  • Results are cached by what was looked up, never by who asked: registration (RDAP and WHOIS) answers for {{ whois_cache }}, in memory{% if subdomains_enabled %}, and subdomain lists on disk, refreshed when a request finds them older than {{ subdomain_cache }}{% endif %}.

What is not collected

  • No cookies, no local storage, no accounts, and no analytics or advertising scripts.
  • The fingerprint panel{% if stun_url %} and the WebRTC leak test{% endif %} run in your browser. What they find is never sent to {{ site_domain }}. The panel's canvas, audio, WebGL and font probes run only when you open it{% if stun_url %}, and the WebRTC test only when you press its button{% endif %}.

Who else the server contacts

These servers see this server's address, not yours. They do learn what was looked up, and on the home page that is your own address.

  • Public DNS resolvers {{ resolvers | join(" and ") }}: the records of the domain you look up, and the reverse-DNS name of an address.
  • RDAP registries, found through IANA's bootstrap files and, for the few registries IANA omits (.ch, .de, .io, .us among them), the list bundled with the whoisit library: the domain or address, sent to the registry or regional internet registry that holds it.
  • WHOIS servers on port 43: the domain, when its registry has no RDAP service or does not answer.
  • The looked-up host itself: a TLS connection to its port 443, to read its certificate.
    • {% if subdomains_enabled %}
  • {{ subdomain_host }}: the domain, and only when you ask for its subdomains.
    • {% endif %} {% if abuseipdb_enabled %}
  • api.abuseipdb.com (AbuseIPDB, in the United States): an IP address you look up directly, to read how often it has been reported for abuse. Never your own address on the home page, and never the address a domain resolves to. Each answer is kept in memory for {{ abuseipdb_cache }}, so an address is asked about at most once in that time.
    • {% endif %}

A .onion or home.arpa name is refused before any of these is asked: nothing public answers for it, and a Tor hidden service's name is sent to none of them.

The server also downloads files that carry nothing about you: the GeoLite2 databases (from {{ geoip_hosts | join(", ") }}), the Public Suffix List ({{ psl_host }}) and IANA's RDAP bootstrap files. Finding an address on the map uses those databases on this server; nobody else is asked.

It also downloads the public lists a lookup's Reputation card checks an address against, once a day each and never for a particular lookup: Spamhaus DROP and ASN-DROP, the Tor Project's exit list, and X4BNet's VPN and datacenter lists (from {{ reputation_hosts | join(", ") }}). Checking an address reads this server's copies, so none of those servers learns what was looked up. A copy older than {{ reputation_max_age }} is reported as not checked rather than used. A dataset older than {{ asinfo_max_age }}{% if asinfo_caida %} ({{ asinfo_caida_rel_max_age }} for CAIDA's relationships and {{ asinfo_caida_org_max_age }} for its organizations, which it publishes less often){% endif %} is reported as unknown rather than used. Source: RIPE NCC. RPKI data validated by rpki-client.org. {% if asinfo_caida %} The CAIDA UCSD AS Relationships Dataset and The CAIDA UCSD AS Organizations Dataset are used under CAIDA's acceptable use terms; the AS card names the date of the file it read.{% endif %}

{% endif %} {% if reverseip_hosts %}

It also downloads OpenINTEL's daily measurement of the public top lists (Tranco, Cisco Umbrella, Cloudflare Radar, Majestic Million and the Chrome UX Report), at most once a day per list and never for a particular lookup, from {{ reverseip_hosts | join(", ") }}. Only the few columns of each file that hold a name and its address are fetched. An IP address lookup's "Domains on this address" panel and a subdomain list read this server's copy, so that server learns nothing about what was looked up. Names from a list older than {{ reverseip_max_age }} are not shown. {{ reverseip_attribution }} The data is used under CC BY-NC-SA 4.0; an unmodified copy of OpenINTEL's terms is kept here.

Who else your browser contacts

  • tile.openstreetmap.org, for the map tiles on a page that shows a map: about 15 requests on a desktop, 6 on a phone.{% if asinfo_hosts %} Zooming or moving the map on an AS page fetches more tiles from the same host.{% endif %} OpenStreetMap sees your IP address and this site's name, but not the page's address, so not what you looked up. The tiles it serves do show which part of the map you are viewing.
    • {% if stun_url %}
  • {{ stun_host }}, a STUN server, and only when you press "Run WebRTC leak test" on the home page. It sees your IP addresses: reporting which ones it sees is the test.
    • {% endif %}
  • Nothing else. Fonts, scripts and styles come from {{ site_domain }}. Links to GitHub, OpenStreetMap{% if subdomains_enabled %}, crt.sh{% endif %} or MaxMind are only followed if you click them.
